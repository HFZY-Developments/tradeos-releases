# TradeOS for Windows

This page holds the releases of TradeOS, the trading system by HFZY Developments: quotations, invoices, stock and accounts, in one place that always balances.

## Installing

Open the latest release (on the right of this page, under **Releases**), download `TradeOS-Setup-<version>.exe` and run it. It installs for the person running it and needs no administrator password.

TradeOS opens only with a licence key issued by HFZY Developments.

## Updates

An installed copy of TradeOS keeps itself up to date. Every download is checked against a statement signed by HFZY Developments before it is installed.

The other files in each release (`TradeOS-Update-<version>.exe`, its `.blockmap` and `latest.yml`) are what installed copies download. People do not need them.

There is no source code here.
